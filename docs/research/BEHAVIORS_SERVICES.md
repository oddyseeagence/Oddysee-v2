# Services Page Behaviors

- Header: preserves the existing header scroll and mobile-menu behavior.
- Service sections: static editorial sections with subtle card and icon hover
  movement; the visual treatment is non-essential.
- CTA links: retain the current rounded purple button treatment and expose clear
  hover and keyboard-focus states.
- Testimonials: reuses the existing auto-advancing carousel and manual controls.
- FAQ: reuses the existing native details/summary accordion.
- Responsive: service copy and visuals alternate only at the large breakpoint;
  every mobile and tablet layout is copy-first and single-column.
- Reduced motion: the global reduced-motion rules suppress non-essential motion.

# Services Page Topology

## Reference system

The page is rebuilt from the five supplied legacy services while using the
existing Oddysee homepage and `a-propos` route as its visual source of truth.

## Page order

1. Existing fixed Oddysee header.
2. White editorial hero with a large `Nos Services` title and short intro.
3. Applications & logiciels service section.
4. Réseaux sociaux service section.
5. Publicité digitale service section.
6. SEO service section.
7. Sites web service section.
8. Existing testimonial carousel.
9. Existing `Tout ce que vous devez savoir` FAQ accordion.
10. Existing Oddysee footer.

## Layout model

- All content remains in normal document flow beneath the fixed header.
- Each service is a full-width section with an `about-container` inner wrapper.
- Desktop service sections use a two-column copy/visual grid and alternate sides.
- Mobile service sections always put copy before the visual.
- Service visuals are decorative, responsive UI illustrations built from the
  existing line-icon language and current design tokens.
